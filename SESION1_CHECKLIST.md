# Antes de clase

Completa [SETUP.md](SETUP.md). Estás preparado cuando:

- Python 3.13 y Git responden en una terminal nueva.
- VS Code abre `omda14-fitlife-workshop` y usa el Python de `.venv`.
- La instalación de `requirements.txt`, `pip check` y `check_setup.py` terminan sin errores.
- La app de prueba responde: al elegir 7 muestra 49 y al cambiar el plan cambia la tabla.
- Has leído [el caso FitLife](ENUNCIADO.md).

Para aquí. En clase, Luis indicará cuándo abrir el ejercicio y os guiará al crear vuestra rama. La preparación no necesita una clave de un modelo.

Si algo falla, conserva el comando y el error completo para revisarlos con Luis. No borres tu trabajo para intentar arreglarlo.
