# Material base del curso

Esta copia de MDA13 conserva la secuencia y los ejercicios que se están mejorando para OMDA14. No es un curso alternativo ni material descartado. Se utiliza para comparar cada mejora con su punto de partida.

Los ejercicios de cada sesión se publican en su rama. Esta copia conserva también los nombres y comandos del proyecto de origen; la instalación actual se explica en el SETUP de la raíz. Las guías de repaso contienen soluciones y Luis decide cuándo utilizarlas.

La procedencia está en [ORIGEN.md](../ORIGEN.md).
