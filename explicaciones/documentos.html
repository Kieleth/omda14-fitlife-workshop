3. El contenido que prepararíamos para enviar
El tamaño se muestra en caracteres de JSON. Un carácter no equivale a un token. La app real muestra el uso de tokens que devuelve la API.


4. Después de recibir una respuesta
  1. Comprueba si cita un fragmento que se envió.
  2. Lee la frase citada: que exista el identificador no demuestra que apoye la conclusión.
  3. Busca condiciones, fechas o documentos que falten. Una búsqueda incompleta puede producir una respuesta incompleta.


¿Lo ha aprendido para siempre?
En este ejercicio no. Añadimos texto a una petición. Una consulta nueva sin ese texto no recibe los documentos, salvo que nuestro código los incorpore de nuevo. Guardar un archivo, incluir contexto y entrenar un modelo son operaciones diferentes.


¿Y un PDF o miles de documentos?
Primero hay que extraer texto legible. Un escaneo puede necesitar reconocimiento de caracteres (OCR). Después siguen las mismas preguntas: cómo dividir, buscar, conservar la fuente y comprobar la respuesta. Los embeddings representan texto con números para buscar por similitud; no convierten automáticamente una coincidencia en evidencia suficiente.
